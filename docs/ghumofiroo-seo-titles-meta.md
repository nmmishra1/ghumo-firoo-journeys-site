## Notes
- Apply the same [Destination] [Trip Type] Package [Year] | [Duration] – Ghumofiroo formula to remaining package pages (Rajasthan, Kerala, Himachal, Goa, Dubai, Singapore-Malaysia, Thailand, Japan, Georgia).
- Keep titles under 60 characters and descriptions under 160 — Google truncates beyond that.
- Every description should end with a soft call to action (Book now / Enquire / Check pricing) — this improves click-through rate even when rankings don't move yet.
